# Testimonio fuente: `ORTEGA1888-TEPIC-IA`

La unidad documental digitalizada es la reimpresión de Tepic de **1888**. CHD no etiqueta sus imágenes ni su OCR como si fueran un escaneo directo de un ejemplar de 1732. La relación documental es:

**obra de 1732 → reimpresión/testimonio de 1888 → digitalización moderna → derivados CHD**.

El registro de Open Library/Internet Archive identifica a José de Ortega, fecha 1888, Imprenta de Antonio Lagaspi y el ejemplar de John Carter Brown Library. También indica que la primera publicación fue México, 1732, y que el vocabulario español-cora ocupa las pp. 15–90.

El PDF tiene 98 páginas físicas. Para el cuerpo léxico, la correspondencia usada inicialmente es página impresa + 4 = página física del PDF. Esta relación se registra como propiedad documental y debe comprobarse durante la reconciliación de artículos.
