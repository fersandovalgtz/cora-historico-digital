# Contribuir

CHD acepta mejoras de código, reglas de extracción, pruebas, metadatos, documentación e interoperabilidad siempre que sean reproducibles y preserven la evidencia previa.

Toda transformación textual automática debe indicar el objeto afectado, la regla aplicada y la evidencia fuente. No se aceptan normalizaciones silenciosas.

El repositorio es machine-only: no existe workflow de revisión humana ni se aceptan contribuciones cuya función sea marcar registros como `human_verified=true`. Una mejora de algoritmo debe expresarse como regla, prueba e impacto reproducible sobre los estados `machine_accepted`, `machine_uncertain` o `machine_rejected`.
