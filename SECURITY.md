# Seguridad

No incluya credenciales, tokens, datos personales sensibles ni secretos en issues, commits o archivos del corpus. Para vulnerabilidades del software, abra un reporte privado mediante las herramientas de seguridad de GitHub cuando estén habilitadas.

Los errores textuales o de datos históricos deben reportarse como problemas editoriales, no como vulnerabilidades de seguridad.
